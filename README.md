# skill-listas-questoes

Skill para agentes (Antigravity) que converte imagens de questões de vestibulares em uma lista de exercícios em LaTeX/PDF.

- `lista-questoes/SKILL.md` — instruções da skill
- `lista-questoes/templates/lista.tex` — template
- `lista-questoes/examples/` — exemplo (ENEM 2020)

## Instalação
Copie a pasta `lista-questoes` para `~/.gemini/config/skills/` (global) ou `.agents/skills/` (projeto).

## Uso
Peça: "use a skill lista-questoes nas imagens deste diretório".
